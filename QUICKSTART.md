# 🚀 Quick Start Guide

## Start Both Servers with One Command

```bash
npm run dev:all
```

This will start both the frontend and backend servers simultaneously using `concurrently`.

## Manual Start (Separate Terminals)

### Terminal 1 - Backend:
```bash
cd server
npm start
```

### Terminal 2 - Frontend:
```bash
npm run dev
```

## Access the App

Open your browser to: **http://localhost:5173**

## Test the Game

1. Open the app in **two browser tabs** (use incognito for the second tab)
2. Click **"Find Match"** in both tabs
3. Wait for matchmaking (should be instant)
4. Game starts automatically!
5. White moves first - drag and drop pieces
6. Chat with your opponent via the chat panel
7. First to checkmate wins! 🎉

## Features to Try

✅ **Find Match** - Join the matchmaking queue  
✅ **Camera Controls** - Toggle video/audio, switch cameras  
✅ **Chat** - Send messages to your opponent  
✅ **Chess Moves** - Drag pieces to make legal moves  
✅ **Resign** - Forfeit the game if needed  
✅ **Play Again** - Start a new game after finishing
